2 워크플로 파일 3개

파일트리거역할
build.ymlworkflow_call (재사용)실제 빌드·게이트·서명 로직 (go/python/java matrix)
harden.ymlpush(main) / tag(v*)변경 시 빌드 → latest(또는 v1.2.3) + sha 태그
daily-rebuild.ymlcron 매일 06:00 UTC전체 재빌드 → latest 갱신 + nightly-YYYYMMDD 보존

harden.yml/daily-rebuild.yml은 둘 다 build.yml을 호출만 한다 (로직 1곳, DRY).

build.yml 핵심 발췌

permissions:
  contents: read
  packages: write     # GHCR push
  id-token: write     # keyless 서명용 OIDC

jobs:
  build:
    strategy: { matrix: { app: [go, python, java] } }
    steps:
      # ① melange → 서명된 .apk (빌드 도구는 여기만)
      - run: docker run --rm --privileged -v "$PWD":/work -w /work \
          cgr.dev/chainguard/melange build melange-${{ matrix.app }}.yaml \
          --arch x86_64 --signing-key keys/melange.rsa

      # ② apko → OCI tar + SBOM
      - run: docker run --rm -v "$PWD":/work -w /work \
          cgr.dev/chainguard/apko build apko-${{ matrix.app }}.yaml \
          "${IMAGE}:${{ inputs.tag }}" /work/image.tar --arch x86_64 --sbom-path /work/sbom

      # ③ CVE 게이트 — HIGH/CRIT 있으면 실패
      - uses: aquasecurity/trivy-action@0.28.0
        with: { input: image.tar, severity: HIGH,CRITICAL, exit-code: "1", ignore-unfixed: true }

      # ④ push (apko OCI tar는 docker-archive 포맷)
      - run: skopeo copy docker-archive:image.tar "docker://${IMAGE}:${{ inputs.tag }}" --dest-creds "$CRED"

      # ⑤⑥ keyless 서명 + SBOM attest
      - run: cosign sign --yes "${REF}"
      - run: cosign attest --yes --type spdxjson --predicate sbom/sbom-x86_64.spdx.json "${REF}"

3 설정 — 이대로만 하면 동작

  • 권한 — 워크플로에 이미 박혀 있음: packages: write(push) + id-token: write(keyless 서명). 이게 없으면 cosign sign 실패.
  • GHCR 시크릿 불필요 — 자동 제공되는 secrets.GITHUB_TOKEN으로 push. 별도 PAT 안 만들어도 됨.
  • 패키지 visibility — 첫 push 후 패키지가 private으로 생김. Repo → Packages → Package settings에서 조정.
  • 이미지 이름 — ghcr.io/<owner>/<repo>-<app> 자동 생성 (예: ghcr.io/acme/hardened-images-java). 치환 불필요.
  • 빌드 아키텍처 — CI는 x86_64(러너 네이티브). 로컬은 arm64라 --arch aarch64; apko/melange 설정에서 archs를 빼 --arch 플래그로 제어.

4 배포측 검증 (선택, 권장)

이미지를 쓰는 쪽에서 우리 워크플로가 서명한 것만 신뢰:

cosign verify ghcr.io/<owner>/<repo>-go@<digest> \
  --certificate-identity-regexp "^https://github.com/<owner>/<repo>/.github/workflows/" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"
☸️
Kubernetes에서 이걸 강제(서명 없으면 Pod 거부)하려면 Kyverno/policy-controller로 위 신원을 검사한다. 구성은 docs/LOCAL-CHAINGUARD.md §5 참고.
